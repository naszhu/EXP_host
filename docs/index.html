REM E3 Front-End Hosting Page

Shuchun Lai (Lea Lai) — Ph.D. Candidate & Researcher

🔍 Overview

This front-end hosts Experiment 3 (E3) in our long-term context memory project. It's built with jsPsych, deployed via Cloudflare Pages, also hosted on firebase. It sends data through a Render backend, and ultimately stores results in Firebase Firestore.

🎓 Dissertation Project

My Ph.D. dissertation explores long-term context memory using the REM (Retrieving Effectively from Memory) model. Key themes include:

  • Context vs. feature similarity in recognition tasks
  • Stage-wise decision thresholds and memory trace strengthening
  • Computational simulations with Julia and Bayesian analyses with Stan

Experiment 3 extends these concepts to multi-list learning, examining how context change by list and word influences recognition performance over time.

⚙️ Features

  • Modular JS under /js/:
    • const_general.js & const_exp.js – parameters
    • helpfunctions.js – utilities
    • load.js – Firebase init & save wrapper
    • main.js – jsPsych timeline & submission
  • Data pipeline:
    1. Client POSTs results to Render endpoint
    2. Render forwards to Firestore via Admin SDK
  • Export script: export_firestore.py (JSON/CSV)
  • Firestore config: firebase.json, firestore.rules, firestore.indexes.json
